# Мой прогресс — приложение для iPhone (PWA)

Рабочая первая версия дневника тренировок и самочувствия. Не требует App Store, аккаунта, платного сервера и базы данных. Интерфейс на русском языке; все пользовательские записи хранятся **локально на устройстве**.

## Что есть

- 8-недельная программа: первые 2 недели — адаптация, с 3-й недели — основной сплит «верх/низ»; четыре занятия в неделю (пн, вт, чт, сб).
- Вес и количество повторений каждого подхода, RIR, подсказка предыдущего рабочего веса, завершение занятия, комментарии.
- Вода: +250 мл, +500 мл, ручной ввод и отмена последнего добавления.
- Питание: добавление приёмов пищи; калории и БЖУ можно не вводить.
- Сон с переходом через полночь, вес, талия, шаги, самочувствие.
- Учёт приёмов препаратов (без рекомендаций по дозировкам).
- Сводка по неделям, изменения веса и рабочих весов.
- Экспорт полной резервной копии в JSON и импорт копии / частичных данных из Excel.
- После первой онлайн-загрузки сайт обычно доступен без Интернета при установке с HTTPS (благодаря service worker).

## Как установить на iPhone

**Вариант: бесплатный GitHub Pages** (публичный репозиторий — только исходники приложения, без личных данных):

1. Создай репозиторий GitHub, например `moy-progress`.
2. Загрузи в корень репозитория **содержимое папки** приложения: `index.html`, `app.js`, `app.css`, `sw.js`, `manifest.webmanifest`, `icons/`.
3. Открой Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Открой предоставленный адрес `https://<имя>.github.io/moy-progress/` на iPhone **в Safari**.
5. В Safari выбери «Поделиться» → «На экран „Домой“» → «Открывать как веб‑приложение» → «Добавить».

Внешнего сервера/публичного URL этот архив сам не создаёт: приложение необходимо разместить на HTTPS-хостинге. При открытии `index.html` локально или через обычный HTTP часть функций PWA не работает.

## Как перенести старую тренировку

В чате есть **отдельный личный файл** `Перенос_моих_записей_из_Excel.json`. Сохрани его в «Файлы» на iPhone. В приложении открой ⚙ → «Импорт JSON» → выбери файл. Этот файл **не входит** в архив сайта: не выкладывай его в GitHub, потому что он содержит личные записи.

## Резервные копии и приватность

Периодически нажимай ⚙ → «Скачать копию» и храни JSON в iCloud Drive или «Файлах». Очистка данных Safari, смена телефона или удаление приложения может удалить локальные записи. Приложение **не синхронизирует** данные между устройствами и не использует Apple Health: это возможные следующие версии при согласовании способа хранения данных.

## Запуск для разработки на компьютере

```bash
python -m http.server 8000
```

Открой `http://localhost:8000` в браузере компьютера. На iPhone установка требует HTTPS, поэтому локальный HTTP-сервер в домашней сети не равнозначен опубликованному веб-приложению.

## Важно про нагрузку

Тренировочный объём рассчитывается как вес × повторы. Для гантелей учитывается вес **одной гантели**, для некоторых тренажёров и упражнений с собственным весом показатель условный. Сравнивай объём одного и того же упражнения, а не всей нагрузки разных упражнений.

## Данные

Хранятся в `localStorage` браузера под ключом `moy-progress-v1`. Резервная копия JSON — единственный доступный в этой версии способ надёжно перенести данные между устройствами.
