# Мой прогресс 2.0 — личный дневник для iPhone

**Готовое статическое веб-приложение (PWA) для GitHub Pages.** Не требует App Store, облачной базы данных, API-ключей, платного хостинга или установки инструментов разработки. Весь интерфейс на русском языке.

## Что нового в 2.0

- **Умная тренировка:** вес и повторы по подходам; отдельная кнопка ✓; автоматический таймер отдыха 60/90/120/180 секунд; перенос прошлых весов в пустые поля; возможность перенести тренировку на другую дату. В статистику выполненных подходов и рекордов входят только отмеченные подходы.
- **Графики и рекорды:** динамика веса тела, талии, сна и рабочих весов; список лучших рабочих весов по упражнениям.
- **Питание:** быстрый ввод, калории/БЖУ (по желанию), избранные блюда, копирование вчерашнего меню, редактирование записей. Приложение не вычисляет калории автоматически по названию — вводи известные тебе данные.
- **Самочувствие:** вода (+250/+500 мл), время и качество сна, шаги, вес, талия, самочувствие; учёт фактического приёма препаратов без медицинских рекомендаций и без автоматического повторения отметки «принято».
- **Фото формы:** фотографии с датой и ракурсом; сравнение двух снимков; уменьшение размера изображения и хранение в локальной базе IndexedDB. Не загружаются на GitHub.
- **Календарь и достижения:** расписание, перенос дат, отметки тренировки в процессе/завершена, динамически рассчитываемые достижения.
- **Резервные копии:** полная копия JSON с фотографиями и историями тренировок, питания и самочувствия. Импорт старых JSON версии 1.0 и файла `fittrack-import` из Excel.

## Важно: как обновиться с 1.0 без потери записей

1. **На iPhone открой старую версию** «Мой прогресс» именно тем способом, которым обычно пользуешься (например, с главного экрана).
2. Открой ⚙ → **Скачать копию**. Сохрани JSON в приложении **Файлы → iCloud Drive** или в другой приватной папке. Убедись, что файл появился в «Файлах»; не отправляй его в публичный репозиторий.
3. На компьютере зайди в свой репозиторий `moy-progress` на GitHub. В корне репозитория должны быть `index.html`, `app.js`, `app.css`, `sw.js`, `manifest.webmanifest` и папка `icons`.
4. **Распакуй ZIP этого обновления** и загрузи его *содержимое* в корень того же репозитория через **Add file → Upload files**. Подтверди замену файлов с совпадающими именами и появление `v2.js`. Нажми **Commit changes**. `README.md` можно заменить.
5. Сохрани Pages: **Settings → Pages → Deploy from a branch → main → /(root)**. После успешного выполнения **Actions → pages build and deployment** открой исходный URL приложения (не создавай новый).
6. Закрой приложение на iPhone и снова открой его. При необходимости обнови страницу Safari и повторно открой иконку приложения. Service worker может потребовать ещё одно закрытие/открытие для обновления файлов.
7. Проверь, что видишь **шесть вкладок**, включая «Календарь», а в «Зале» — таймер отдыха. Открой сохранённые тренировки, чтобы убедиться, что они на месте.
8. Если данные отсутствуют: **⚙ → Импорт JSON** → выбери сохранённую копию с iPhone. Прежде чем импортировать, убедись, что исходные данные действительно не подгрузились: полный импорт *заменяет* текущие записи тренировок и питания.

**Не удаляй прежнюю иконку приложения, не очищай данные Safari и не меняй адрес GitHub Pages до проверки.** Safari и установленная PWA могут хранить данные в разных контейнерах. Если переходишь с Safari на иконку или наоборот и записи не появились, используй экспорт/импорт JSON.

## Размещение впервые на GitHub Pages

- Создай публичный репозиторий, например `moy-progress`.
- В корне репозитория размести **файлы из ZIP**, а не дополнительную папку `fittrack_iphone` или `fittrack_v2`.
- Включи Settings → Pages → `Deploy from a branch`, ветка `main`, папка `/ (root)`.
- Твой URL имеет вид `https://USER.github.io/moy-progress/`.
- На iPhone открой URL в **Safari**, затем **Поделиться → На экран «Домой» → Добавить**.

Для работы сайта используется HTTPS. Service worker кеширует файлы, что позволяет открывать оболочку приложения после первой загрузки при отсутствии сети. **Офлайн-работу и сохранение данных на конкретной версии iOS необходимо проверить отдельно.**

## Хранение данных и приватность

- Совместимый формат v1 хранится в `localStorage` под прежним ключом **`moy-progress-v1`**: новая версия не очищает и не переименовывает его.
- Фотографии сохраняются в **IndexedDB** `moy-progress-photos`, отдельно от `localStorage`. В полной резервной копии они включены в виде закодированных изображений. Фото автоматически уменьшаются до 1000 пикселей по длинной стороне.
- Сайт не отправляет данные на сервер и не имеет аккаунта или облачной синхронизации. GitHub Pages публикует **только код**, если ты не загрузишь туда личные файлы самостоятельно.
- **Не загружай на GitHub** резервные JSON-файлы, фото формы, записи о препаратах и любую персональную историю.
- Очищение данных Safari, удаление веб-приложения, смена устройства или исчерпание локального места могут уничтожить записи; делай регулярную резервную копию.
- При импорте полного JSON приложение спрашивает подтверждение замены текущих данных. Частичный импорт старого `fittrack-import` объединяет записи.
- **Препараты:** журнал служит только для фиксации факта приёма. Приложение не назначает дозировки и не напоминает самостоятельно о приёме.

## Структура файлов

```
index.html               интерфейс и навигация
app.css                  стили для iPhone и десктопа
app.js                   логика v1, хранение совместимых данных
v2.js                    новая функциональность, фото и графики
sw.js                    офлайн-кэш версии 2.0.0
manifest.webmanifest     параметры PWA
icons/                   иконки приложения
README.md                это руководство
```

Для локального теста на ПК: `python -m http.server 8000` в каталоге приложения и открыть `http://localhost:8000/`.

## Ограничения

Приложение не интегрировано с Apple Health, не делает медицинских заключений, не получает список калорий из продуктовой базы и не синхронизируется между устройствами. Рабочие веса и тоннаж по тренажёрам/гантелям приблизительные и не равны показателю реальной механической работы. Истинную производительность PWA нужно подтвердить на своём iPhone в Safari.
